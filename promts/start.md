Все ассеты разложи по папкам внутри public.

Отдельно сформируй файлы стилей.

Перенеси все js скрипты с сохранением функциональности.

В исходном html/css есть недоступные изображения в конце переноса выдай их списком.

Создай отдельный конфиг в котором будут храниться адреса на которые будет вестись рассылка сообщений с форм.
